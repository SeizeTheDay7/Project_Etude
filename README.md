박자에 맞추어 노트에 맞는 방향키를 누르는 2D 리듬 게임. Unity 1인 개발.

> 판정 로직 구현

- 방향키를 누르면 판정 막대의 앞뒤로 raycast를 쏴서 고속 이동할 때도 정확히 판정될 수 있게 함
- dspTimeGap을 누적하여 사용하여 프레임에 관계 없이 판정 막대의 정확한 위치를 보장

> 맵 에디터 구현

- 맵 에디터 씬에서 UGUI 기반 UI를 클릭하면 노트 블럭의 추가, 변경, 삭제 가능
- 맵 저장은 내장 JSONUtility로 구현해본 뒤, 코드의 복잡성을 줄이기 위해 Easy Save 애셋 도입
- 맵 에디터를 이용하여 1일 만에 5개의 맵 완성
